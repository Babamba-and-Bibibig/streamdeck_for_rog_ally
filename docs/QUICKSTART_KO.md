# OrangeDeck 간단 사용법

**Mac은 작업용, ROG Ally는 리모컨입니다.** Mac에서는 macOS와 Codex를, Ally에서는 CachyOS Handheld의 데스크톱 모드를 사용합니다. Steam Deck·SteamOS는 아직 확인하지 않았습니다.

[처음 설치](../README.md#설치하기) · [설치 도움말·업데이트](INSTALL.md)

## 켜기

두 기기의 Tailscale을 켜고, **Mac 먼저 → Ally** 순서로 실행하세요.

**Mac 터미널:**

```sh
sh "$HOME/.config/orangedeck/start-connector.command"
```

**Ally 터미널:**

```sh
sh "$HOME/.config/orangedeck/start-ui.sh"
```

Mac 터미널은 켜 두세요. Ally에 **연결됨**이 보이면 프로젝트와 대화를 골라 확인합니다.

예전 소스 폴더 방식으로 설치했다면 이번 업데이트에서 Mac의 Setup을 한 번 실행하세요. 이후 Mac은 **Start OrangeDeck Connector.command**, Ally는 **기존 프로젝트 폴더에서 `./scripts/run-ally.zsh`**로 켭니다. 설정 폴더를 따로 지정했다면 설치 끝에 안내된 실행 파일을 사용하세요.

## 끄기

- **Ally:** 앱 창을 닫습니다.
- **Mac:** 통신 모듈이 켜진 터미널에서 **Ctrl+C**를 누릅니다.

다시 켤 때마다 재설치하거나 연결 파일을 다시 옮길 필요는 없습니다.

## 화면별 사용법

| 화면 | 이렇게 쓰세요 |
| --- | --- |
| **LIVE** | 지금 하는 작업의 토큰과 5시간·주간 남은 사용량을 봅니다. |
| **단축키** | 표시된 요청을 승인·거절하거나, 내가 넣은 기능을 실행합니다. |
| **프로젝트들** | 확인할 작업 폴더를 고릅니다. 다른 탭도 같은 폴더로 바뀝니다. |
| **대화** | 한 대화를 골라 계속 봅니다. 최근 대화를 보려면 **최근 자동**을 누릅니다. |
| **알림** | 현재 질문과 답변, 완료 알림을 읽습니다. 승인할 내용도 여기서 자세히 봅니다. |

**자동 ON**이면 선택한 프로젝트의 최근 대화가 자동으로 보입니다. 대화를 직접 고르면 그 대화를 계속 보여줍니다. 다른 프로젝트의 대화로 저절로 넘어가지는 않습니다.

토큰 숫자는 새 사용 기록을 받을 때 바뀝니다. 작업이 끝나도 마지막 숫자는 남고, 새 작업을 시작하면 새로 셉니다. 남은 사용량은 **100%에서 시작해 쓸수록 줄어듭니다.** 확인할 수 없는 값은 `—`로 표시합니다. 남은 비율을 토큰 개수로 바꿔서 표시하지는 않습니다.

## 승인·거절하기

새 승인 요청이 오면 **단축키** 탭으로 이동하고 **01 승인·02 거절**이 깜빡입니다. 요청이 여러 개면 **‹ / ›** 또는 **LT / RT**로 바꿔 봅니다. 지금 선택한 대화에 온 요청만 보여줍니다.

**긴 내용은 요청 상세를 열고 안쪽을 스크롤해 끝까지 읽은 뒤 결정하세요.** Mac 통신 모듈 0.1.21부터 전달받은 전체 명령·권한·파일 변경 내용을 상세 화면에 보여줍니다.

| 버튼을 누르는 위치 | A 버튼 | B 버튼 |
| --- | --- | --- |
| **단축키 탭** | 선택한 키 실행 | 표시된 요청 거절 |
| **알림 탭의 승인 카드** | 표시된 요청 승인 | 표시된 요청 거절 |
| **질문·완료 팝업** | 내용 보기 | 읽음 처리하고 닫기 |
| **키 편집창** | 저장 | 취소 |

승인 요청이 없거나 연결이 끊기면 승인·거절 키는 회색이고 눌러도 실행되지 않습니다. 한 번 누른 뒤 결과를 기다리는 동안에도 잠깁니다. 키보드 Enter·Escape·Space로는 승인을 보내지 않습니다. 앱이 뒤에 있을 때 누른 패드 입력도 사용하지 않습니다. 일반 질문에는 **Mac Codex에서** 답하세요.

## 내 버튼 만들기·언어 바꾸기

1. **단축키 → 빈 + 버튼 → 기능 선택**으로 저장합니다. 그 버튼을 다시 눌러야 기능이 실행됩니다.
2. **추천 구성**을 누르면 빈 버튼을 한 번에 채웁니다. 이미 넣은 기능은 유지합니다.
3. **키 편집 → 바꿀 버튼**에서 기능을 바꾸거나 **키 비우기**로 지웁니다. 마우스 오른쪽 클릭으로도 편집할 수 있습니다. 01 승인·02 거절은 고정입니다.
4. 오른쪽 위 **한국어 / EN**으로 언어를 바꿉니다. 대화 내용과 프로젝트 이름은 원래 글을 그대로 보여줍니다.

탭 열기, 새로고침, 최근 대화 자동 보기, 이전/다음 프로젝트·대화, Mac의 에디터·터미널·폴더·웹페이지 열기 중에서 고릅니다. **앱이나 폴더를 여는 버튼은 Mac에서 실행됩니다.** [Mac에 다른 작업 폴더 추가하기](INSTALL.md#host-shortcuts).

언어와 버튼 배치는 자동으로 저장합니다. 직접 설정 파일을 고칠 필요는 없습니다. 저장 위치는 Ally의 `~/.config/orangedeck/ui-preferences.toml`입니다. 예제 모드에서 바꾼 설정은 앱을 끄면 사라집니다.

## 패드로 이동하기

- **방향키·왼쪽 스틱:** 선택 위치 이동
- **LB / RB:** 이전·다음 탭
- **LT / RT:** 프로젝트·대화 또는 승인 요청 바꾸기
- **Y:** 현재 질문의 알림 보기
- **X:** 새로고침

터치와 마우스로도 조작할 수 있습니다. 키보드는 방향키로 이동하며 Q/E로 탭을, Z/C로 프로젝트·대화를 바꿉니다. 승인·거절은 터치·마우스 클릭 또는 새로 누른 패드 A/B로 결정하세요.

## 연결이나 알림이 안 되면

Mac의 통신 모듈이 켜져 있는지, 두 기기의 Tailscale이 켜져 있는지부터 확인하세요. 처음 알림을 연결할 때는 **통신 모듈 실행 → Enable Codex Notifications.command → Codex `/hooks`에서 OrangeDeck 확인·신뢰** 순서가 필요합니다. [연결 검사와 문제 해결](INSTALL.md#연결이나-알림이-안-될-때).

처음 연결한 뒤에는 Mac에서 새 작업을 해 보고 Ally의 새 숫자·완료 알림을 확인하세요. 실제 승인 요청이 왔을 때 버튼을 눌러 Mac에 전달되는지도 확인해야 합니다.
