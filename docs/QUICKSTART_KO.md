# OrangeDeck 간단 사용법

**테스트한 구성은 Mac Studio(macOS, 작업용 메인 PC) + ASUS ROG Ally(CachyOS Handheld, 리모컨)입니다.** Ally는 데스크톱 모드에서 사용합니다.

**메인 PC는 macOS만 지원하며, Linux·Windows 메인 PC는 미지원입니다.** Windows 리모컨도 미지원이며, 다른 Linux 배포판·Steam Deck·SteamOS·다른 핸드헬드의 리모컨 동작은 미검증입니다.

[처음 설치](../README.ko.md#설치하기) · [설치 도움말·업데이트](INSTALL.md)

## Mac의 세 파일은 각각 무엇인가요?

**세 `.command` 파일 모두 메인 PC의 macOS용 실행 스크립트입니다. 처음 설치할 때 ① → ② → ③ 순서로 두 번 눌러 실행하세요.**

| 파일 | 하는 일 | 실행 후 |
| --- | --- | --- |
| **① Setup OrangeDeck.command** | 통신 모듈 설치·업데이트와 개인 설정 준비 | **설치 완료 후** 안내에 따라 Enter를 누르고 창 닫기 |
| **② Start OrangeDeck Connector.command** | Mac과 Ally 사이의 통신 실행 | **사용하는 동안 터미널 켜 두기** |
| **③ Enable Codex Notifications.command** | Codex 완료 알림·승인 요청 연결 설정 | **설정 완료 후** 안내에 따라 Enter를 누르고 창 닫기 |

③이 끝나면 **Mac의 평소 Codex에서 `/hooks` → OrangeDeck 항목 확인·신뢰**를 진행합니다. Mac에서 계속 켜둘 OrangeDeck 창은 **② 통신 모듈 하나**입니다. **다음부터는 Start만 실행합니다.** Codex와 Tailscale은 평소처럼 켜 두세요.

**업데이트할 때:** 새 폴더의 Setup을 실행해 설치를 마칩니다. 이전 **통신 모듈 터미널**에서 Ctrl+C를 누른 뒤 새 Start를 실행하고, Enable → Codex `/hooks` 확인·신뢰까지 진행합니다. Ctrl+C는 OrangeDeck 통신 모듈 창에서만 누릅니다. [업데이트 순서](INSTALL.md#업데이트).

**Ally의 Linux(CachyOS Handheld)에서는 이 세 파일을 실행하지 않습니다.** 설치·업데이트할 때만 압축을 푼 폴더에서 `sh install.sh --role ui`를 실행하고, 평소에는 아래의 Ally 실행 명령으로 앱을 켭니다.

## 설정을 다시 묻지 않아도 되나요?

**네. 이미 설치했다면 저장해 둔 내 설정을 그대로 쓰기 때문입니다.** 작업 폴더·편집기·연결 설정은 각 기기의 `~/.config/orangedeck/`에 남습니다. GitHub 다운로드에는 개인 설정이나 비밀 연결 인증값이 들어 있지 않습니다.

처음 받는 사람은 자기 Mac에서 설정과 새 인증값을 만들고, 자기 Ally에 연결 파일을 등록합니다. 다른 사람이 앱을 받는 것만으로 내 Mac에 연결되지는 않습니다. 연결에는 **내 Mac에 접속할 수 있는 Tailscale 연결과 내 연결 인증값**이 모두 필요합니다. [설명·편집기 변경](INSTALL.md#saved-settings).

## 켜기

**설치와 알림 연결을 마쳤다면 아래 두 실행 명령만 사용하세요.** 두 기기의 Tailscale을 켜고, **Mac 먼저 → Ally** 순서로 실행합니다. Setup·Enable을 매번 다시 실행하지 않습니다.

**Mac 터미널:**

```sh
sh "$HOME/.config/orangedeck/start-connector.command"
```

**Ally 터미널:**

```sh
sh "$HOME/.config/orangedeck/start-ui.sh"
```

Mac 통신 모듈 터미널은 켜 두세요. 위 명령으로 Ally 앱을 띄웠다면 그 터미널도 앱을 사용하는 동안 켜 둡니다. Ally에 **연결됨**이 보이면 프로젝트와 대화를 골라 확인합니다.

예전 소스 폴더 방식으로 설치했다면 이번 업데이트에서 Mac의 Setup을 한 번 실행하세요. 이후 Mac은 **Start OrangeDeck Connector.command**, Ally는 **기존 프로젝트 폴더에서 `./scripts/run-ally.zsh`**로 켭니다. 설정 폴더를 따로 지정했다면 설치 끝에 안내된 실행 파일을 사용하세요.

## 끄기

- **Ally:** 앱 창을 닫습니다.
- **Mac:** 통신 모듈이 켜진 터미널에서 **Ctrl+C**를 누릅니다.

다시 켤 때마다 재설치하거나 연결 파일을 다시 옮길 필요는 없습니다.

## 화면별 사용법

| 화면 | 이렇게 쓰세요 |
| --- | --- |
| **LIVE** | 지금 하는 작업의 토큰과 5시간·주간 남은 사용량을 봅니다. |
| **에이전트들** | 다섯 Codex 대화의 응답과 수정 파일을 위아래 버튼으로 봅니다. |
| **프로젝트들** | LIVE·대화에서 확인할 폴더를 고릅니다. 에이전트들의 대화 연결은 유지됩니다. |
| **대화** | 한 대화를 골라 계속 봅니다. 최근 대화를 보려면 **최근 자동**을 누릅니다. |

**자동 ON**이면 선택한 프로젝트의 최근 대화가 자동으로 보입니다. 대화를 직접 고르면 그 대화를 계속 보여줍니다. 다른 프로젝트의 대화로 저절로 넘어가지는 않습니다.

토큰 숫자는 새 사용 기록을 받을 때 바뀝니다. 작업이 끝나도 마지막 숫자는 남고, 새 작업을 시작하면 새로 셉니다. 남은 사용량은 **100%에서 시작해 쓸수록 줄어듭니다.** 확인할 수 없는 값은 `—`로 표시합니다. 남은 비율을 토큰 개수로 바꿔서 표시하지는 않습니다.

## 다섯 대화 연결하기

1. **에이전트들 → 위쪽 + 버튼**을 누릅니다.
2. Mac 터미널에서 쓰는 Codex 대화를 고르고, 버튼 이름을 정합니다.
3. 같은 열의 위아래 버튼이 그 대화에 함께 연결됩니다. 최대 다섯 대화를 연결할 수 있습니다.

연결을 바꾸려면 **대화 연결 → 위 버튼**을 누르세요. **연결 비우기**로 지울 수 있습니다. 다른 탭에서 프로젝트나 대화를 바꿔도 이 연결은 유지됩니다.

## 응답·승인·수정 파일 보기

새 응답이나 승인 요청이 오면 **같은 열의 두 버튼이 함께 깜빡이고 소리가 납니다.** 다른 화면을 보고 있어도 저절로 화면이나 창이 바뀌지는 않습니다.

응답·승인·수정 파일은 모두 **에이전트들**에서 확인합니다. 탭은 **LIVE·에이전트들·프로젝트들·대화** 네 개입니다.

| 누를 곳 | 하는 일 |
| --- | --- |
| **위 버튼** | 해당 질의와 Codex 응답을 창으로 보여줍니다. |
| **응답 창의 승인 / 거부** | 표시된 요청을 Mac에 전달하고, 전달되면 창을 닫습니다. 긴 내용은 요청 상세 안쪽을 스크롤해 읽으세요. |
| **아래 버튼** | 수정 파일 목록 창을 엽니다. 파일명·전체 경로·변경 줄을 확인합니다. |
| **목록의 파일** | Mac 편집기에서 그 파일의 기록된 변경 줄을 엽니다. 코드 내용은 Mac에서 확인합니다. |
| **파일 수정 없음** | 이번 질의에 기록된 파일 편집이 없습니다. 눌러도 창이나 편집기는 열리지 않습니다. |
| **파일 정보 확인 / 확인 중** | 눌러서 파일 창을 열고, Mac의 기록을 다시 가져옵니다. 확인되면 목록에 표시하고, 실패하면 재시도할 수 있습니다. |
| **창 바깥 / 닫기 / 패드 X** | 창만 닫습니다. 승인·거절은 보내지 않습니다. |

파일 목록은 그 질의에서 Codex가 기록한 파일 편집을 보여줍니다. 기록을 끝까지 읽고 같은 질의의 성공한 편집 기록도 확인합니다. 터미널 명령·외부 도구의 편집 기록이 부족하면 **파일 정보 확인**을 표시합니다. 삭제한 파일은 이름·경로·삭제 표시만 보며, 아직 정보를 받는 중이면 **확인 중**으로 구분합니다. 변경 줄 위치가 기록되지 않았으면 파일 첫 줄부터 엽니다.

응답 창에 요청이 여러 개면 **‹ / › 또는 LT / RT**로 고릅니다. **패드 A는 표시된 요청 승인, B는 거절**입니다. 요청이 없는 응답 창과 파일 창에서는 **B로 닫습니다.** 키보드 Enter·Escape·Space는 승인·거절을 보내지 않으며, Escape는 창만 닫습니다. 앱이 뒤에 있을 때 누른 패드 입력은 무시합니다. 승인 요청을 받지 않았다면 **이 질의에 전달된 승인 요청이 없습니다**라고 표시합니다. 일반 질문에는 **Mac Codex에서** 답하세요.

**Mac 편집기:** 처음 설치할 때 고른 Zed·VS Code·Cursor·VSCodium을 사용합니다. 바꾸려면 [편집기 설정](INSTALL.md#host-shortcuts)을 보세요. **연결한 Codex 대화의 작업 폴더를 자동으로 기준 삼습니다.** 폴더 경로를 입력하거나 등록할 필요 없이, 목록에서 파일을 누르면 그 대화에서 수정·생성한 파일이 Mac 편집기에서 열립니다. 목록을 열거나 새로 고치는 것만으로 편집기가 실행되지는 않습니다.

파일이 열리지 않으면 목록 위의 큰 오류 안내를 확인하고 **다시 시도**하세요. **0.1.33의 목록 화면·언어 전환은 Ally UI를 업데이트하면 적용되며, 기존 0.1.31 Mac 통신 모듈과 호환됩니다.** Mac의 변경 이벤트로 바뀐 파일만 가져오며 폴더 전체를 다시 찾지 않습니다. 아직 파일 수집을 지원하지 않는 구버전은 [업데이트 안내](INSTALL.md)에 따라 업데이트하고 알림 훅을 확인·신뢰하세요. 이후 작업부터 수집하며, 이전에 없던 기록을 복원하지는 않습니다. [수집 범위와 제한](INSTALL.md#host-shortcuts).

## 언어·알림음 바꾸기

- 오른쪽 위의 큰 **한국어 / English** 버튼으로 언어를 고릅니다. 선택한 언어는 주황색으로 표시되고 바로 적용되며 다음 실행에도 유지됩니다. 창이 떠 있다면 먼저 닫으세요. 프로젝트 이름·질의·응답·승인할 명령은 원문 그대로 보여줍니다.
- 에이전트들 위의 **소리 켜짐/꺼짐**로 알림음을 켜고 끕니다.
- 언어·대화 연결·소리 설정은 자동 저장됩니다. 저장 위치는 Ally의 `~/.config/orangedeck/ui-preferences.toml`입니다. 예제 모드는 앱을 끄면 설정이 사라집니다.

## 패드로 이동하기

- **방향키·왼쪽 스틱:** 선택 위치 이동
- **LB / RB:** 이전·다음 탭
- **LT / RT:** 프로젝트·대화 또는 승인 요청 바꾸기
- **Y:** 에이전트들 열기
- **X:** 새로고침, 창이 열려 있으면 닫기

터치와 마우스로도 조작할 수 있습니다. 키보드는 방향키로 이동하며 Q/E로 탭을, Z/C로 프로젝트·대화를 바꿉니다. 승인·거절은 터치·마우스 클릭 또는 새로 누른 패드 A/B로 결정하세요.

## 연결이나 알림이 안 되면

Mac의 통신 모듈이 켜져 있는지, 두 기기의 Tailscale이 켜져 있는지부터 확인하세요. 처음 알림을 연결할 때는 **통신 모듈 실행 → Enable Codex Notifications.command → Codex `/hooks`에서 OrangeDeck 확인·신뢰** 순서가 필요합니다. [연결 검사와 문제 해결](INSTALL.md#연결이나-알림이-안-될-때).

처음 연결한 뒤에는 Mac에서 새 작업을 해 보고 Ally의 새 숫자·완료 알림을 확인하세요. 실제 승인 요청이 왔을 때 버튼을 눌러 Mac에 전달되는지도 확인해야 합니다.
