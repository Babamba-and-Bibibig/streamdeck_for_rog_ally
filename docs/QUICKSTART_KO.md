# OrangeDeck 간단 사용법

[처음 설치](../README.ko.md#설치하기) · [설치 옵션과 업데이트](INSTALL.md)

## 켜기

1. **Agent 기기:** 설치기가 생성한 `start-agent.command`를 실행하고 터미널을 켜 둡니다. 기본 위치는 `~/.config/orangedeck/start-agent.command`입니다.
2. **Linux 화면 기기:** 생성된 `start-ui.sh` 또는 개인 바로가기를 실행합니다. 기본 위치는 `~/.config/orangedeck/start-ui.sh`입니다.
3. 두 기기의 Tailscale이 켜져 있고 UI에 **CONNECTED**가 표시되는지 확인한 뒤 Codex로 작업합니다.

사용자 설정 위치를 바꿨다면 설치기가 알려준 경로를 사용합니다. 기존 소스 폴더 설치는 Mac의 `Start OrangeDeck Agent.command`, Linux의 `./scripts/run-ally.zsh`로 계속 실행할 수 있습니다. Linux 명령은 압축을 풀었던 프로젝트 폴더의 터미널에서 실행합니다.

새 설치기의 기본 위치를 사용했다면 다음 명령을 각 기기 터미널에 복사하면 됩니다.

Agent 기기:

```sh
sh "$HOME/.config/orangedeck/start-agent.command"
```

Linux 화면 기기:

```sh
sh "$HOME/.config/orangedeck/start-ui.sh"
```

## 사용하기

- **1 · LIVE:** 현재 질의의 토큰을 가장 큰 숫자로 봅니다. 완료 후에도 집계 시각과 함께 남으며, 새 질의가 시작되면 이전 숫자를 비웁니다. 집계 대기·수신 지연·연결 끊김 상태를 구별해 표시합니다. 아래에는 OpenAI가 실제로 제공한 5시간·주간 한도를 모델/대상별 **가로 막대와 남은 비율(%)**로 표시합니다. 아래로 스크롤하면 추가 한도와 서버 제공 일별·누적 토큰·크레딧을 볼 수 있습니다. 유효하지 않은 한도는 `—`이며, 제공되지 않은 기간의 숫자를 만들지 않습니다.
- **2 · 단축키:** 정사각형 키 **5개씩 2줄, 총 10개**입니다. **01 승인 / 02 거절**은 위에 표시된 현재 질의의 승인 요청 한 건에 적용합니다. 새 승인 요청이 오면 이 탭으로 자동 이동하고 두 키가 점멸합니다. 내용을 확인한 뒤 키를 누르세요. **요청 상세**는 알림 탭에서 명령·경로 등의 상세 내용을 엽니다. **03~10은 미지정**이며 기능은 추후 정합니다. 승인 요청이 없거나 연결 확인 중·전송 중이면 두 결정 키는 동작하지 않습니다.
- **3 · 프로젝트들:** Mac Codex에 기록된 프로젝트 전체 수와 최근 활성 프로젝트 수를 확인합니다. 판단 대기·작업 중인 프로젝트를 먼저, 나머지는 최근 활동 순으로 보여줍니다. 폴더를 누르면 모든 탭의 대상이 함께 바뀝니다.
- **4 · 대화:** 선택한 프로젝트의 대화만 최근 활동 순으로 나옵니다. 최신 질문을 크게, 저장된 대화 제목은 그 아래에 표시합니다. **현재 LIVE** 표시가 있는 대화가 LIVE·단축키·알림과 같은 대화입니다. 탭을 열면 그 대화로 이동하며, 다른 대화를 선택하면 함께 반영됩니다. 최신 질문을 읽지 못한 경우에는 이를 표시합니다. 과거 대화 상세 창은 없습니다.
- **5 · 알림:** 선택한 대화의 **현재 질의 한 건**과 해당 응답을 크게 봅니다. 일반 판단 질문이나 응답 완료가 오면 **밝은 알림 탭·화면 테두리·큰 중앙 팝업**으로 알립니다. 팝업은 확인할 때까지 남습니다. 팝업의 **내용 보기 · A**는 상세 알림을 열고, **확인했어요 · B**는 읽음 처리합니다. 실제 승인 요청은 2번 단축키 탭으로 이동하며, 알림 탭에서도 요청을 읽고 **A 승인 / B 거부**로 응답할 수 있습니다. 일반 질문의 답변은 Mac Codex에서 선택합니다.

단축키의 승인·거절 키는 상태에 따라 다음처럼 보입니다.

- **요청 없음:** 두 키가 같은 회색이며 ‘요청 없음’이 표시됩니다. 마우스를 올려도 밝아지거나 실행되지 않습니다.
- **승인 대기:** 승인 키는 초록, 거절 키는 분홍으로 함께 점멸합니다. 두 키 모두 마우스를 올리면 배경·테두리가 밝아지고 손 모양 커서가 나오며, 누르는 동안에는 흰 테두리로 반응합니다.
- **연결 대기 / 준비 중 / 전송 중:** 두 키가 다시 회색으로 잠기고 해당 상태가 표시됩니다.

단축키의 자동 이동은 **현재 선택한 대화의 현재 질의**에 승인 요청이 있을 때만 적용됩니다. 같은 요청으로 다른 탭을 계속 빼앗지 않습니다. 요청이 여러 개면 상단 **‹ / ›** 또는 **LT / RT**로 요청을 바꿉니다. 단축키 탭의 방향키/스틱은 5×2 키 사이를 이동하고, 물리 **A는 선택한 키 실행**, **B는 표시된 요청 거절**입니다. 실행 가능한 요청이 있을 때 작은 **A 표시**가 패드로 선택한 키를 알려줍니다. 이 표시는 마우스 호버와 별개입니다. 미지정 키에는 동작이 없습니다. Enter/Escape/Space로 승인을 보내지 않습니다.

화면 위 **프로젝트 선택** 또는 LIVE 폴더 카드의 **‹ / ›**로 프로젝트를 바꿀 수 있습니다.
**최근 자동**을 누르면 선택한 프로젝트에서 가장 최근에 활동한 대화로 돌아가고, 이후에도 최신 대화를 따라갑니다. 켜져 있으면 버튼이 밝은 **자동 ON**으로 표시됩니다. 앱 시작과 프로젝트 선택 직후에는 기본으로 켜져 있으므로, 이미 최신 대화를 보고 있을 때 누르면 같은 화면이 유지됩니다. 대화 탭에서 특정 대화를 직접 고르면 **대화 고정**으로 바뀌며, 다시 **최근 자동**을 누르면 자동 선택으로 돌아갑니다. 다른 프로젝트나 Mac에서 맨 앞에 띄운 창으로 이동하는 버튼은 아닙니다.
한도 막대의 큰 숫자는 **남은 비율(%)**이며, 옆의 **사용 N%**는 이미 쓴 비율입니다. 예를 들어 Spark를 쓰지 않았으면 **100% 남음 · 사용 0%**가 맞습니다. 두 비율은 합해서 100%이며 토큰 개수와 별개입니다. 프로젝트 토큰은 약 5초, 공식 한도는 약 15초, 계정 통계는 약 60초 간격으로 확인합니다. 계정 통계의 세부 집계 범위는 별도로 확인되지 않았으며 서버 집계에는 지연이 있을 수 있습니다.
활성 수는 최근 2분 안의 작업 활동 또는 현재 승인 대기 기준이며, Mac에서 열어 둔 창 개수는 아닙니다.

현재 질의 토큰은 모델 요청이 완료되어 기록될 때 갱신되며 매 토큰 실시간 증가가 아닙니다. 질의 전체의 합계를 확정할 수 없으면 **최근 모델 요청 토큰**으로 표시합니다. 계정에 따라 공식 5시간·주간 항목이 다를 수 있으며 제공된 대상·기간만 표시합니다.

## 끄기 · 다시 켜기

- **화면 앱:** 창의 닫기 버튼을 누릅니다.
- **Agent:** 작업이 끝난 뒤 해당 Agent 터미널에서 **Ctrl+C**를 누릅니다.
- **다시 켜기:** 위 ‘켜기’의 해당 실행기를 다시 실행합니다.

일반 재실행에는 다운로드·빌드·페어링·훅 설치를 반복할 필요가 없습니다. 화면 앱을 닫아도 평소 사용하던 Codex 대화는 계속됩니다.

## 처음 알림 연결 · 업데이트

**Agent 실행 → 알림 설치 실행기 → 평소 Codex의 `/hooks` 검토·신뢰** 순서입니다. [알림 안내](NOTIFICATIONS_KO.md)를 따르세요. 경로나 훅 정의가 바뀌면 신뢰를 다시 검토합니다. 업데이트는 새 소스 폴더에서 같은 역할·설정 위치로 설치기를 실행한 다음 기존 Agent를 직접 종료하고 다시 켭니다.

**Agent 0.1.18 이하에서 0.1.19로 업데이트할 때는** 알림 경로 변경 때문에 위 알림 설치·신뢰 순서를 한 번 더 진행합니다. 기본 위치의 알림 설치 명령은 `sh "$HOME/.config/orangedeck/enable-notifications.command"`입니다. 이후 일반 재실행에는 반복하지 않습니다.

## 실행이 안 될 때

- Mac command가 안 열리면 소스 폴더 터미널에서 `sh install.sh --role agent`로 처음 설치를 진행하거나 생성된 실행기 경로를 입력합니다.
- 설치 중 ‘설정 없이 남은 인증 파일’ 안내가 나오면 기존 설정을 복원·확인하거나 새 설정 폴더를 선택합니다. 기존 토큰을 자동으로 덮어쓰지 않기 위한 중단입니다. [설치 안내](INSTALL.md)를 따르세요.
- 연결이 안 되면 두 기기의 Tailscale과 Agent 터미널, 허용된 네트워크 정책을 확인합니다.
- 새 설치기의 진단 명령은 Agent 기기에서 `sh "$HOME/.config/orangedeck/check-agent.command"`, 화면 기기에서 `sh "$HOME/.config/orangedeck/check-ui.sh"`입니다. 사용자 지정 설치는 안내받은 경로를 사용합니다.
- 알림이 없으면 Agent 실행·알림 설치·`/hooks` 신뢰와 Codex 사용자/프로필이 같은지 확인합니다.
- 입력 장치가 여러 개이고 일부에 접근할 수 없으면 UI는 사용 가능한 패드를 탐색합니다. 임의로 시스템 장치 권한을 바꾸지 않습니다.

새 환경의 실제 토큰·알림·자연 발생 승인 왕복은 본인 기기에서 확인해야 합니다. 모의 검사만으로 실기기 동작 완료를 뜻하지 않습니다.
