OrangeDeck 다운로드 페이지

현재 업데이트: ${version}

Mac 업데이트 다운로드

  1. Mac의 Safari에서 위 버튼을 누릅니다. Finder의 다운로드에서 ${archive}을 더블클릭합니다.
  2. 압축을 푼 OrangeDeck-v${version}/streamdeck 폴더를 엽니다.
  3. 진행 중인 OrangeDeck 작업이 끝나면 기존 Agent 터미널에서만 Ctrl+C를 누릅니다.
  4. 새 폴더의 Setup OrangeDeck.command를 실행합니다. 본인 프로젝트를 설정하거나 기존 설정을 유지하여 빌드·설치합니다. 그다음 안내된 start-agent.command로 Agent를 실행하고 터미널을 열어 둡니다.
  5. 같은 폴더의 Enable Codex Notifications.command를 실행합니다. 평소 쓰는 Codex의 완료·승인 알림을 연결하는 별도 단계입니다.
  6. Mac Codex에서 /hooks를 입력하고 OrangeDeck 항목을 검토·신뢰합니다. 새 항목이 안 보이면 현재 작업이 끝난 뒤 같은 대화를 다시 열어 확인합니다.

command 파일이 열리지 않으면 Mac Terminal에 zsh 를 입력하고, 파일을 터미널로 끌어 넣은 뒤 Return을 누르세요.

처음 사용하는 Linux 화면 기기는 소스 폴더에서 sh install.sh --role ui를 실행하고, Agent가 만든 비밀 페어링 파일을 선택하세요. 기존 설정이 있는 기기는 페어링을 유지합니다.
